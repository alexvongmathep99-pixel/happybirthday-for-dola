# Happy Birthday Dola 🤍

## ວິທີເບິ່ງ
ເປີດ `index.html` ດ້ວຍ browser ໄດ້ເລີຍ (ບໍ່ຈຳເປັນຕ້ອງ npm install).
ຫຼືໃຊ້ VSCode: `npm install` ຄັ້ງດຽວ ແລ້ວ `npm run dev` → http://localhost:3000

## ແກ້ຂໍ້ຄວາມ / ຮູບ / ເພງ (ຢູ່ເທິງສຸດຂອງ <script> ໃນ index.html)
- `MESSAGE`   ຂໍ້ຄວາມຫຼັກ (English)
- `REASONS`   "Why I love you" — ປ່ຽນເປັນເລື່ອງຈິງຂອງເຈົ້າ ຈະຊຶ້ງໃຈກວ່າ
- `photos`    ໃສ່ຮູບ: ວາງໄຟລ໌ຮູບໄວ້ຂ້າງ index.html ແລ້ວເພີ່ມ
              `{ src: "photos/1.jpg", caption: "The day we met" }`
- `MUSIC_SRC` ວາງໄຟລ໌ `music.mp3` ຂ້າງ index.html ປຸ່ມ ♪ ຈະຂຶ້ນເອງ
- ວັນເກີດ 4 ຕຸລາ ແລະ ວັນຄົບຮອບ 1 ພຶດສະພາ 2022 ແກ້ໄດ້ໃນຟັງຊັນ `nextBirthday` / `updateTogether`
